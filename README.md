# PD Signal Analysis

Веб-приложение для анализа сигналов акселерометра и гироскопа с целью классификации болезни Паркинсона.

## Быстрый старт

### Windows
1. Скачайте репозиторий (ZIP или git clone)
2. Запустите `start.bat` (двойной клик)
3. Откройте браузер: http://localhost:8000
4. Загрузите папку с CSV файлами

### Linux/Mac
```bash
chmod +x start.sh
./start.sh
